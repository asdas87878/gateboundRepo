# NPCs and challenges

## Decided (the user, 2026-11-08)
- **No main quest line.** Where to go should be self-explanatory: no hand-holding.
- **Challenges instead:** kill 20 enemies of a type, beat the second boss. Finishing them brings NPCs to your base.
- **NPCs are saved in the Lands** and come home as vendors, like Terraria.

## Ideas on the table (Claude, not agreed)
- **NPCs work at the base while you're out:** the gardener grows herbs, the smith smelts ore.
- **One house per NPC**, with the number of houses set by the town hall's level.
